# Manual de usuario de Acordes del Barrio

El manual de usuario completo de la versión 1.1 está en [docs/Manual_de_Usuario_Acordes_del_Barrio.pdf](docs/Manual_de_Usuario_Acordes_del_Barrio.pdf).

Contiene ocho páginas revisadas: instalación y primer acceso; registro e inicio de sesión; consulta de recursos y reservas; consulta y cancelación; administración de usuarios y recursos; conexión y solución de problemas; uso responsable y práctica guiada.

API pública: https://acordes-del-barrio-api.onrender.com/

El APK de Moodle es Acordes-del-Barrio-Render-1.1.apk. No se incluyen contraseñas en el manual ni en el repositorio.
